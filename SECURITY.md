# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.

Include the browser and version, steps to reproduce, and the impact you observed. You should get a reply within 7 days.

## Scope

Context Handoff runs only on `https://claude.ai/*`, has no network code, and stores data only in `chrome.storage.local`. Reports about data leaving the browser, script injection through chat content, or permission misuse are especially welcome.
