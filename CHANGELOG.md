# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-25

### Added
- Floating Handoff button on claude.ai with light/dark theme support.
- Compact mode (task goal, latest version of each named file, last N messages) and Full transcript mode.
- XML resume prompt (copy to clipboard) and Markdown export (download).
- HTML-to-Markdown conversion with code blocks, tables, lists, blockquotes and KaTeX math.
- Usage-limit notice detection and an optional reset reminder notification.
- Popup with saved handoffs (last 20), reminder and settings.
- `Alt+Shift+H` keyboard shortcut.
- Offline dev harness and Node test suite.
