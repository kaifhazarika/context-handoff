Continue a long Claude chat in a fresh one, without losing context

Context Handoff is a free, open-source Chrome extension that turns a long claude.ai conversation into a compact handoff: the task goal, the latest version of every file, the last few messages and your next step. Copy it as a resume prompt or download it as Markdown.

What is Context Handoff?

Context Handoff is a Manifest V3 browser extension for Chrome, Edge and Brave. It reads the conversation open on claude.ai and exports it in one of two forms. A resume prompt is an XML-structured prompt you paste into a new chat. A Markdown file is something you attach or keep as notes. All processing happens in your browser. It makes no network requests and never reads cookies, sessions or credentials.

Why hand off instead of continuing?

Use fewer tokens

Every message in a long chat re-sends the whole thread. A compact handoff is usually a small fraction of that size.

Get better answers

Models answer more reliably from a short, focused context than from 100 turns of old debugging.

Take your work anywhere

Continue in a new chat, on another device or browser profile, or in a different AI assistant.

Keep a clean record

The Markdown export keeps code blocks, tables and LaTeX math, so it reads well as project notes.

How to continue a long Claude chat in a new chat

  1. Install Context Handoff and open the long chat on claude.ai.
  2. Click the ⇄ Handoff button, or press Alt+Shift+H.
  3. Choose Compact for coding tasks or Full transcript for research and writing, and optionally type the next step.
  4. Click Copy resume prompt and paste it into a new chat, or click Download .md and attach the file.

What a compact handoff looks like

<handoff mode="compact" source="TEC plotting script">
<instructions>You are continuing a task that started in an earlier conversation...</instructions>
<task_goal>Write a Python script that loads TEC data from a CSV and plots it.</task_goal>
<current_files>
  <file name="analysis.py" language="python"> ...latest version... </file>
</current_files>
<note>5 earlier message(s) were left out to save space.</note>
<recent_conversation> ...last 6 messages... </recent_conversation>
<next_step>Add a colorbar</next_step>
</handoff>

Features

Compact modeTask goal, the latest version of each named file, and the last N messages (6 by default).
Full transcriptEvery message verbatim, for research, writing and review threads.
Clean MarkdownCode blocks with language tags, tables, lists, links, blockquotes and KaTeX math.
Two exportsCopy an XML resume prompt, or download a .md file.
Limit noticeThe button lights up when the usage-limit message appears, and an optional reminder fires when it resets.
Saved handoffsThe last 20 handoffs in the popup, stored only on your device.
PrivateNo network code, no analytics, no remote scripts. MIT licensed.

Frequently asked questions

How do I export a Claude conversation to Markdown?

Install Context Handoff, open the chat on claude.ai, click Handoff, choose Full transcript and click Download .md. The file keeps every message, code blocks with language tags, tables and math.

How do I continue a Claude chat in a new conversation without losing context?

Use Compact mode and Copy resume prompt, then paste it into a new chat. The prompt carries the original goal, the current version of each file, the most recent messages and your next step.

Does Context Handoff send my data anywhere?

No. The extension has no network code. It builds the handoff in your browser and stores at most 20 recent handoffs locally in chrome.storage.local.

Can I use the handoff with ChatGPT, Gemini or another assistant?

Yes. The resume prompt is plain text with simple XML tags that any capable chat model understands, and the Markdown file can be attached anywhere.

Does it help get around usage limits?

No. It does not manage accounts or change how any service counts usage. It makes your context smaller and portable so the usage you have goes further.
